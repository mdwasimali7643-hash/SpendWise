# 💰 SpendWISE

### Track. Budget. Spend Smarter.

SpendWISE is a modern, simple expense tracker built to help you manage your income, expenses, and monthly budget.

## ✨ Features

- 💰 Track income and expenses
- 📊 Expense analytics
- 🎯 Monthly budget tracking
- 🔎 Search transactions
- ✏️ Edit transactions
- 🗑️ Delete transactions
- 💱 Multiple currencies
- 🔐 Firebase authentication
- ☁️ Cloud data storage
- 📱 Installable as a PWA
- 🌙 Modern dark interface
- 👤 Account-based data isolation

## 🛠️ Built With

- HTML
- CSS
- JavaScript
- Firebase Authentication
- Cloud Firestore
- GitHub Pages
